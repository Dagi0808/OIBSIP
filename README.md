# Python Voice Assistant

## Overview
This project is a Python-based voice assistant built for the OIBSIP task.

## Features
- Voice input recognition
- Text-to-speech responses
- Time and date queries
- Web search
- Weather lookup
- Reminder support
- Email integration
- Custom commands

## Tech Stack
- Python
- SpeechRecognition
- pyttsx3
- requests
- python-dotenv
- PyAudio

## Project Structure
- src/ : application source files
- config/ : configuration and command definitions
- screenshots/ : demo screenshots
- .env.example : template for environment variables

## Installation
1. Create and activate a virtual environment.
2. Install dependencies using pip.
3. Copy .env.example to .env and populate secrets.

## Privacy Considerations
Do not commit real credentials or personal data. Keep secrets in a local .env file and exclude it from git.
